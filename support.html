Report a chat message

If a chat message is inappropriate or violates the Community Guidelines:

  1. Press and hold the message.
  2. Select Report.
  3. Explain why you are reporting it.
  4. Submit the report.

Authorised moderators can review the report and either dismiss it or remove the reported message.

Block a user

From a venue chat:

Press and hold the user's message → Block → confirm

You can also block another user from the Network user list.

Blocking:

  • hides their venue-chat messages from you;
  • hides their message reactions from you;
  • prevents certain future message, check-in and event notifications generated by that user from being sent to you.

Blocking is one-way.

It does not hide the user's presence, pseudonym/avatar, events or places.

The other user is not directly notified that you blocked them.

Unblock a user

Open the Network user list.

Blocked users are identified as blocked.

Press and hold the user and select Unblock.

Account deletion

You can initiate account deletion from:

Profile → Delete account

If you cannot access the app, see the Account Deletion page or contact support.
